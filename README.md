# 🤖 ServeBot – Customer Support Chatbot
ServeBot is a web-based customer service chatbot built using **Flask** and basic **NLP** techniques. It is designed to handle common customer queries and provide automated responses through an interactive chat interface.

## 🚀 Features
* 💬 Interactive chat interface
* 🧠 NLP-based query matching (CountVectorizer + Cosine Similarity)
* ⚡ Fast and simple response system
* 🌐 Web-based application using Flask
* 🎨 Clean UI with chat bubbles
* ⌨️ Enter key support for sending messages
* 🤖 Bot avatar for better user experience

## 🛠️ Technologies Used
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python (Flask)
* **NLP:** Scikit-learn (CountVectorizer, Cosine Similarity)

## ▶️ How to Run
* ```bash
  python app.py
* Open in browser:
  http://127.0.0.1:5000/

## 💡 How It Works
* User enters a query in the chat interface
* Input is processed using NLP techniques
* The system finds the most similar predefined question
* Corresponding response is returned to the user
